# game10033-a2-drawing - "The Hill"
This is a small program created for Assignment 2: 2D Interactive Drawing. It displays a small scene of a house on a hill where keyboard inputs can change the season and the time.
Press ASDF keys on the left side of your keyboard to change the season between spring, summer, fall, and winter respectively.
Press the up and down arrow keys on the right side of your keyboard to change the time. Up for day, down for night.
The big tree and the sun/moon are on the sides of the screen that correspond to their keyboard inputs, which I thought was neat.
